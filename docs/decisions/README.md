# Architectural decision records (ADRs)

Records of genuinely contested design decisions — a real alternative
existed and the reasoning for not choosing it is worth preserving.
Indexed from [`../architecture.md`](../architecture.md) §11. Created via
the `architecture-doc` agent / `/document-architecture` prompt using
`.github/skills/architecture-docs/references/adr-template.md`, only when
the `architecture-docs` skill's threshold for one is actually met — most
changes don't need one. Number sequentially: `0001-<slug>.md`,
`0002-<slug>.md`, ...
